Knitter

Build. Stitch. Ship.

Knitter is a small static site generator that weaves together templates, data, and styles into fast, predictable websites. Using Jinja, SCSS, and JSON with a simple TOML config, it keeps your build process transparent and easy to reason about. Perfect for projects that don’t need a full framework. Create static webpages without clutter, simple and straight to the point.
