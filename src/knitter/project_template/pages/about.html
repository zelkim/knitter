What is Knitter?

Knitter is a lightweight, Python-based static site generator designed to make building content-driven websites simple and transparent. Originally created to power the Dev8 community’s 2023 survey results page, it uses a minimal TOML configuration to define your site’s routes, asset processing, and data sources. Knitter stitches together Jinja2 templates, JSON data, and SCSS into ready-to-deploy static HTML, letting you focus on writing templates and content instead of build scripts.

With two intuitive commands — knitter build to generate your dist/ deployable site and knitter serve to run a live-reloading development server — Knitter streamlines both development and production workflows. SCSS files are compiled via an external Dart Sass executable, and CSS is optionally minified for production, while static assets from your defined assets folder are copied straight through into the final build.

The heart of every Knitter project is knitter.toml, where you tell it where to find your assets, how to process source files, what URL routes to generate, and which JSON datasets to make available to your templates. This keeps projects readable and portable across environments without hidden convention logic.
